
## 两层电梯、三层电梯

事件：
- `up`: 电梯上移
- `down`: 电梯下移
- `idle`: 电梯驻留
- `req?i`: 收到来自第`i`层的请求（来自每层的控制器）
- `goto?j`: 收到前往`j`层的请求（来自电梯内按键）
- `door`: 电梯开门后关门


**P.S.** 做以下假设
- 使用者会正确使用电梯，包括正确按键以及进出电梯；
- 无并发、监听，电梯进行服务时不会响应其他请求；
- 电梯初始停靠在1层；
- 控制器/按键不会向电梯进程传递不存在的楼层。

**PPS.** 事实上这个模型可以对应任意层数的单电梯服务

```
alphabet:

α(ELE) = { req.i | i∈Floor }
         ∪ { goto.j | j∈Floor }
         ∪ { up, down, door, idle }
         
α(ELEVATOR) = α(ELE)
```

```
GOTO(i,j) = if (i<j) then (up -> GOTO(i+1, j))
			else if (i==j) then (SKIP)
			else (down -> GOTO(i-1, j)) 

ELE(i) = req?j -> ( 
			GOTO(i,j) ; door -> goto?k -> (
				GOTO(j,k) ; door -> idle -> ELE(k)
			)
		)
					   
ELEVATOR = ELE(1)
```
## 双电梯两层


事件：
- `upA`, `upB`: 电梯A/B上移
- `downA`, `downB`: 电梯下移
- `idleA`, `idleB`: 电梯驻留
- `reqA?i`, `reqB?i`: 收到来自第`i`层的请求（来自每层的控制器）
- `gotoA?j`, `gotoB?j`: 收到前往`j`层的请求（来自电梯内按键）
- `doorA`, `doorB`: 电梯开门后关门

**P.S.** 做以下假设
- 使用者会正确使用电梯，包括正确按键以及进出电梯；
- 无并发、监听，每台电梯进行服务时不会响应请求；
- 电梯初始停靠在1层；
- 控制器/按键不会向电梯进程传递不存在的楼层；
- A, B两台电梯有各自独立的控制器和电梯内按钮。


**PPS.** 事实上这个模型可以对应任意层数的独立双电梯服务

```
alphabet:

α(ELE_A) = { reqA.i | i∈Floor } 
			∪ { gotoA.j | j∈Floor } 
			∪ { upA, downA, doorA, idleA }

α(ELE_B) = { reqB.i | i∈Floor } 
			∪ { gotoB.j | j∈Floor } 
			∪ { upB, downB, doorB, idleB }

α(ELEVATOR) = α(ELE_A) ∪ α(ELE_B)
```

```
UP(id) = if (id==1) then (upA -> SKIP) else (upB -> SKIP)
DOWN(id) = if (id==1) then (downA -> SKIP) else (downB -> SKIP)

GOTO(i,j,id) = if (i<j) then (UP(id) ; GOTO(i+1, j, id))
			   else if (i==j) then (SKIP)
			   else (DOWN(id) ; GOTO(i-1, j, id)) 

ELE_A(i) = reqA?j -> ( 
				GOTO(i,j,1) ;
				doorA -> gotoA?k -> ( 
					GOTO(j,k,1) ;
				    doorA -> idleA -> ELE_A(k) 
				) 
			)
				  
ELE_B(i) = reqB?j -> ( 
				GOTO(i,j,2) ;
				doorB -> gotoB?k -> ( 
					GOTO(j,k,2) ;
					doorB -> idleB -> ELE_B(k) 
				) 
			)
					   
ELEVATOR = ELE_A(1) || ELE_B(1)
```

## 同一控制的双电梯两层

事件：
- `upA`, `upB`: 电梯A/B上移
- `downA`, `downB`: 电梯下移
- `idleA`, `idleB`: 电梯驻留
- `req?i`: 控制器收到来自第`i`层的请求（来自每层的控制器）
- `gotoA?j`, `gotoB?j`: 电梯A/B收到前往`j`层的请求（来自电梯内按键）
- `doorA`, `doorB`: 电梯开门后关门
- `ask`: 控制器向所有电梯发送查询指令，期望收到每台电梯所在楼层

通信：
- `instA`,`instB`: 控制器向A/B电梯发送前往第i层的指令
- `posA`, `posB`: 电梯向各自的状态进程更新自身状态
- `ansA`, `ansB`: A/B电梯状态进程向控制器回复`ask`指令询问的楼层信息。如果繁忙则回复`MAX_INT`。

进程：
- `ELE_A`, `ELE_B`: 电梯主体进程，负责执行运动
- `STATE_A`, `STATE_B`: 电梯状态进程，负责回应控制器
- `CTRL`: 控制器进程，负责接收请求以及分发指令

**PS.** 做以下假设
- 使用者会正确使用电梯，包括正确按键以及进出电梯；
- 无并发、监听，两台电梯均在进行服务时或者控制器正在处理请求时不会响应请求；
- 电梯初始停靠在1层；
- 通信中不会出现不存在的楼层；
- A, B两台电梯有各自独立的控制器和电梯内按钮。

**PPS.** 这个模型可以对应任意层数的双电梯服务，只要保证楼层数小于`MAX_INT/2`即可。

``` 
alphabet:

α(CTRL) = { req.i | i∈Floor }
          ∪ { ask }
          ∪ { ansA.i, ansB.i | i∈Floor ∪ {MAX_INT} }
          ∪ { instA.i, instB.i | i∈Floor }
          
α(ELE_A) = { instA.j | j∈Floor }
           ∪ { posA!v | v∈Floor ∪ {MAX_INT} } 
           ∪ { gotoA.k | k∈Floor } 
           ∪ { upA, downA, doorA, idleA }

α(STATE_A) = { posA?j | j∈Floor ∪ {MAX_INT} } 
             ∪ { ask }
             ∪ { ansA!i | i∈Floor ∪ {MAX_INT} }

α(ELE_B) = { instB.j | j∈Floor }
           ∪ { posB!v | v∈Floor ∪ {MAX_INT} }
           ∪ { gotoB.k | k∈Floor }
           ∪ { upB, downB, doorB, idleB }

α(STATE_B) = { posB?j | j∈Floor ∪ {MAX_INT} }
             ∪ { ask }
             ∪ { ansB!i | i∈Floor ∪ {MAX_INT} }
             
α(ELEVATOR) = α(CTRL) ∪ α(ELE_A) ∪ α(STATE_A) ∪ α(ELE_B) ∪ α(STATE_B)

```


```
UP(id) = if (id==1) then (upA -> SKIP) else (upB -> SKIP)
DOWN(id) = if (id==1) then (downA -> SKIP) else (downB -> SKIP)

GOTO(i,j,id) = if (i<j) then (UP(id) ; GOTO(i+1, j, id))
			   else if (i==j) then (SKIP)
			   else (DOWN(id) ; GOTO(i-1, j, id)) 
			   
DIFF(x,y) = if (x>=y) then (x-y) else (y-x)

__CHOOSE(i,j,k) = if ( i==MAX_INT && j==MAX_INT ) then (SKIP)
				else (
					if (DIFF(i,k)<=DIFF(j,k)) then (instA!k -> SKIP)
					else (instB!k -> SKIP)
				)

CHOOSE(k) = ask -> (
				  (ansA?i -> ansB?j -> __CHOOSE(i,j,k)) 
				| (ansB?j -> ansA?i -> __CHOOSE(i,j,k)) 
			) 

CTRL = req?i -> CHOOSE(i) -> CTRL

ELE_A(i) = instA?j -> posA!MAX_INT -> ( 
				GOTO(i,j,1) ;
				doorA -> gotoA?k -> ( 
					GOTO(j,k,1) ;
					doorA -> idleA -> posA!k -> ELE_A(k) 
				) 
			)
		 
STATE_A(i) = (posA?j -> STATE_A(j)) | (ask -> ansA!i -> STATE_A(i))
				  
ELE_B(i) = instB?j -> posB!MAX_INT -> ( 
				GOTO(i,j,2) ;
				doorB -> gotoB?k -> ( 
					GOTO(j,k,2) ;
					doorB -> idleB -> posB!k -> ELE_B(k) 
				) 
			)

STATE_B(i) = (posB?j -> STATE_B(j)) | (ask -> ansB!i -> STATE_B(i))
					   
ELEVATOR = ( (ELE_A(1) || STATE_A(1)) || (ELE_B(1) || STATE_B(1)) ) || CTRL
```
